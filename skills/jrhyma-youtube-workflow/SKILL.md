# JRhyma YouTube workflow

Start with an idea, recording, or transcript. Read [../../templates/jrhyma-voice.md](../../templates/jrhyma-voice.md) for brand context. Refine the voice only from actual JRhyma speech samples or explicit preferences.

## Flow

1. **Research:** Verify current claims and dates. Compare videos against each channel's own median with `yt-viral` and `swipe.py` where data permit. Patterns are hypotheses, not proven causes.
2. **Promise:** Name the viewer and one payoff the video can deliver. Never invent figures, endorsements, or results.
3. **Script:** Use `yt-script` for several hooks and a complete spoken script with on-screen cues. Deliver the payoff and estimate runtime from spoken word count. Use `yt-edit` for transcript-based edit notes.
4. **Packaging:** Use `yt-package` for title and thumbnail as a pair. Avoid repeated wording; make the thumbnail legible on a phone.
5. **Discovery:** Use `yt-seo` for a truthful description and relevant queries. Use `yt-chapters` only with actual timestamps.
6. **Shorts:** Use `yt-shorts` with a recording for clips with real timecodes. Otherwise write new Short concepts and label them as concepts.
7. **Schedule and learn:** Use `yt-plan` for a feasible cadence, `yt-retention` or `yt-audit` when data exist, and `yt-comment` for draft responses.

For an end-to-end request, deliver the production packet with footage and factual checks still needed. If actual generation, editing, or publishing is requested, use separately available tools and verify the result. The original eleven skills prepare content but do not upload it.

## JRhyma guardrails

- Use JRhyma as the creator name. Minnesota travel is one possible series; do not assume a fixed niche.
- Do not expose private family, employment, legal, or precise location details without explicit direction.
- Do not imply a partnership or endorsement unless confirmed.
- Keep the spoken style provisional until real samples are available.
